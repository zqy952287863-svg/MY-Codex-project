# 开通家庭同步（一次设置，两台共用）

云服务选择 Supabase。使用你自己的账号和免费项目，不需单独租服务器。本仓库不会包含家庭码或云服务管理密钥。免费方案是否可用及限制以服务商页面为准；两台手机均需能访问项目域名，建议选择邻近区域。

1. 打开 https://supabase.com/dashboard ，登录并创建一个项目。数据库密码只在服务商页面填写，不要发到聊天或填写到 APP。
2. 项目就绪后，打开左侧 SQL Editor，新建查询，把本目录 `supabase.sql` 的完整内容复制进去，点击 Run。脚本只新增 `baoli_families` 表和三个家庭 RPC，禁止匿名用户直接读取表。再次运行不会清空已有数据。
3. 在项目的 Connect / Settings → API / API Keys 中找到 Project URL 与公开 Publishable key（或旧版 anon key）。不要使用 Secret / service_role key。
4. 先在记录最完整的那台手机备份，再升级 APP 1.5，在左侧“档案备份”→“家庭同步”→“第一台手机：建立家庭”，填写 URL 和公开 key，点击“用本机记录建立家庭”。
5. 第一台显示家庭码后，长按复制，私下分享给另一台。在另一台升级 APP、先备份，再在“档案备份”中粘贴家庭码，点击“加入家庭”。第二台会采用家庭共同记录，**不自动上传自己的旧记录或初始样例**。如果第二台也有独有记录，应先备份，连接后再补录这些数据。

以后任一台保存体重会立即尝试上传。另一台在 APP 前台每约10秒检查一次；重新打开或恢复联网时也会同步。APP 关闭或被系统挂起时不会后台运行，重新打开后拉取。断网不会丢弃本机待传修改，联网后重试。

两台分别修改不同记录会合并。两台同时把同一条记录改成不同内容时不会静默覆盖，会提示在“档案备份”选择保留自己的待同步修改或采用云端。修改中接收到云端更新时保留未保存输入，提交前会提示确认，未改动的输入项不会覆盖云端新值。页面筛选、所选幼犬等仍各自在手机上保存，不打扰另一台的操作。

家庭码含随机256位访问凭据，拥有它的人可读写共同记录，只分享给家人。APK 和公开仓库不包含这个凭据。JSON 数据备份不包含连接配置，重装后用家庭码重新加入。断开家庭只断开当前手机，不删除云端和另一台数据。已连接家庭时需先断开才能恢复本机备份，防止恢复旧备份覆盖共同记录。

测试包括客户端并发合并、离线重启、冲突处理，以及两份独立浏览器存储模拟夫妻两台手机。实际 Supabase 项目尚需用户开通，开通后才能做在线两手机验证。下载 APK 本身不会自动建立云数据库。
